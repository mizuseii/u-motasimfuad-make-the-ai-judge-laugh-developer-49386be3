The .env File I Never Committed — one funny single-line developer excuse for when code breaks in production: "It works on my machine because my machine has the .env file I never committed to production." It turns the worn "works on my machine" excuse by revealing the real cause: the machine only works because it holds the .env file that never reached production.

## Run it

```sh
node main.ts
```

This writes the excuse to `/output/entry.txt` (UTF-8, under 200 characters).
